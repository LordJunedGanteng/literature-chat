Cara pakai

1. Tanya kayak ngobrol

Ketik topik di chat. Bot nyari jurnal beneran di OpenAlex / Crossref dan nampilin hasilnya sebagai kartu.

  • precarity animation workers
  • gender gap VFX industry 2018-2025 open access
  • generative AI creative work terbaru
  • pelecehan seksual industri kreatif paling banyak disitasi

2. Filter langsung di kalimat

  • Tahun: 2018-2024, dari 2015, sebelum 2020, 5 tahun terakhir
  • Akses: open access / gratis
  • Urutan: terbaru, paling banyak disitasi / populer
  • Sumber: pakai crossref

3. Masukin ke tabel

Klik + Tabel di kartu, atau ikon “tambah semua” di bawah jawaban. Tabel otomatis berformat kolom xlsx (NO, LINK, TAHUN, REFERENSI, RINGKASAN). RINGKASAN diisi draft dari abstrak (masih bahasa Inggris) — klik selnya buat edit.

4. Export

Menu Tabel xlsx → Download .xlsx, atau Copy ke Excel lalu paste ke file lama lo. Bisa juga ketik download di chat. Ikon 📎 di kotak chat buat impor file .xlsx lama.

Catatan

Istilah umum bahasa Indonesia otomatis diterjemahin ke Inggris biar hasilnya lebih banyak. Semua data (tabel & riwayat) cuma disimpan di browser ini.
