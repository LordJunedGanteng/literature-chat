Koneksi GitHub

Saklar maintenance disimpan di file status.json di repo. Buat ngubahnya, admin butuh token GitHub. Token cuma disimpan di browser ini, ga pernah ikut ke repo.

  1. Buka github.com → Fine-grained token baru
  2. Repository access: Only select repositories → literature-chat
  3. Permissions → Contents: Read and write
  4. Generate, lalu tempel token di bawah
